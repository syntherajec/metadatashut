ℹ️ How It Works
1. Upload JPG/PNG preview images of your EPS vectors.
2. Generate — AI analyzes each image visually and creates:
  • Description (max 200 chars, English, US market)
  • Keywords (30–49, English, SEO-optimized)
  • Categories (from Shutterstock official list)
3. Download ZIP — CSV is ready to upload directly to Shutterstock.

Filename: Automatically changed from .jpg/.png → .eps
Illustration: Always set to "yes" for vector files
Key rotation: Multiple keys rotate automatically to avoid rate limits
